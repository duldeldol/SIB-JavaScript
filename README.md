# Studi Independen Bersertifikat (SIB) - JavaScript

Repositori ini berisi kumpulan tugas dan proyek latihan praktikum JavaScript pada program **Studi Independen Bersertifikat (SIB)**. Setiap direktori pertemuan memuat implementasi kode program beserta dokumentasi tangkapan layar (*screenshot*) hasil eksekusi.

## 📝 Rincian Materi Tiap Pertemuan

### 📌 [Pertemuan 1](./Pertemuan%201/) - Perhitungan Luas Bangun Datar
- **Deskripsi**: Program antarmuka web interaktif untuk menghitung luas berbagai bentuk bangun datar (Persegi, Persegi Panjang, dan Segitiga).
- **Materi**: Dasar HTML, CSS Styling modern, JavaScript DOM Manipulation, Event Listener, dan Validasi Input.
- **File**: `tugas1.html`, `Pertemuan 1.png`

---

### 📌 [Pertemuan 2](./Pertemuan%202/) - Sistem Penggajian & Tunjangan Pegawai
- **Deskripsi**: Aplikasi web interaktif untuk mengelola dan menghitung data gaji pegawai secara otomatis dengan tabel ringkasan data.
- **Materi**: Logika Percabangan (*Conditional Statements* `if-else` / `switch`), Perhitungan Gaji Pokok, Tunjangan Jabatan, Tunjangan Keluarga, Iuran BPJS, Total Gaji, dan Manipulasi Tabel HTML secara dinamis.
- **File**: `tugas2.html`, `Pertemuan 2.png`

---

### 📌 [Pertemuan 3](./Pertemuan%203/) - Manajemen Data Produk Toko
- **Deskripsi**: Program JavaScript berbasis CLI / Node.js untuk mengelola inventaris produk toko menggunakan manipulasi array dan objek.
- **Materi**: Struktur data *Array of Objects*, fungsi CRUD (menambah produk dengan `push`, menghapus berdasarkan ID dengan `findIndex` & `splice`), serta menampilkan visualisasi data menggunakan `console.table`.
- **File**: `tugas3.js`, `Pertemuan 3.png`

---

### 📌 [Pertemuan 4](./Pertemuan%204/) - Sistem Manajemen Rental Transportasi (OOP)
- **Deskripsi**: Implementasi konsep *Object-Oriented Programming* (OOP) dalam memodelkan sistem transaksi sewa kendaraan pelanggan.
- **Materi**: *Class*, *Constructor*, Pewarisan (*Inheritance* `extends` & `super` pada Class `Mobil` dan `Motor` dari Class induk `Kendaraan`), Enkapsulasi data relasi penyewaan pada Class `Pelanggan`, serta agregasi data menggunakan `console.table`.
- **File**: `tugas4.js`, `Pertemuan 4.png`

---

### 📌 [Pertemuan 5](./Pertemuan%205/) - Fitur Manajemen Produk Toko Modern (ES6+)
- **Deskripsi**: Program JavaScript untuk manajemen katalog produk toko online yang memanfaatkan fitur-fitur modern ES6+ untuk meningkatkan efisiensi dan fleksibilitas kode.
- **Materi**: *Event Listener & Custom Event Handler* (mekanisme notifikasi aksi data), *Destructuring Object* (ekstraksi data produk), *Spread Operator* (penambahan data array secara immutable), dan *Rest Parameter* (fleksibilitas penanganan argumen penghapusan produk).
- **File**: `tugas5.js`, `Pertemuan 5.png`

---

## 📄 Lisensi & Catatan
